QNN LPAI API Revision History¶

2.30.0

2.46.0

5.18.x

  • Improved Elemwise Ops(Add/Sub/Mul): broadcast handling,shape inference,mixed‑dim tensors.

  • Reduce Op: More reliable axis handling when reducing tensors without keeping dimensions.

  • GEMM/FullyConnected Ops: Improved slicing,execution efficiency for dense compute workloads.

  • Norm Ops(LayerNorm/RMSNorm): Improved numeric stability and accuracy in quantized models.

  • Transpose,Reformat Ops: Bug fixes and broader layout support improve model portability.

  • More accurate output shape propagation reduces downstream mismatches.

  • Improved correctness of Quantized Op single‑channel and edge‑case quantization scenarios.

  • Runtime improvements that reduce failures when handling model input/output buffers.

  • Improved reliability during model initialization and execution start‑up.

  • Add support for setting Power modes (eNPU clocks, DSP voltage corners, etc).

5.17.x

  • Improved overall stability and accuracy across supported workloads.

  • Better reliability for convolution-based and quantized models.

  • Improved handling of pooling, padding, and shape transformations.

  • Increased robustness of elementwise ops (Add, Sub, Mul, broadcast patterns) execution.

  • Increased robustness of GEMM/MatMul execution.

  • Expanded support for a broader range of vision, audio, and transformer-style models.

  • Improved efficiency of matrix ops(GEMM/MatMul), elemwise ops, normalization flows.

  • Above improvements benefiting modern neural networks.

  • Enhanced stability for sequence-based workloads (GRU/RNNstyle models) and quantized models

  • Improved runtime performance, profiling, and mem-management for more predictable execution.
