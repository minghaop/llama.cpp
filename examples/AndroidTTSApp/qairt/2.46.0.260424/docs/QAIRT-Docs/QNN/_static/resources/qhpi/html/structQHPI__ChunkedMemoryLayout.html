Detailed Description

Descriptor for a chunked (blocked) memory layout.

Describes how tensor data is organized in memory as a sequence of dimension chunking rules, ordered from slowest to fastest varying.

For flat layouts, dim_info_size equals rank and each entry has chunk_size == 0 (meaning the full extent). The default flat layout is:

{4, 4, {{0,0},{1,0},{2,0},{3,0}}}

For crouton (blocked) layouts, additional entries with non-zero chunk_size describe the blocking structure. For example, 8-bit crouton:

{4, 7, {{0,0},{1,0},{2,0},{3,0}, {1,8},{2,8},{3,32}}}

For indirect (block-table) tensors, entries with non-zero chunk_size define individual block dimensions, and entries with chunk_size == 0 define the block table indexing. Blocks are typically 2 KB.
