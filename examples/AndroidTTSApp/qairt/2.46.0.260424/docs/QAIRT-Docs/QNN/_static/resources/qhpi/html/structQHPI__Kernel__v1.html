Detailed Description

Description of a single kernel implementation for an operator.

A kernel is one concrete implementation of an operator, targeting specific tensor types, layouts, and hardware resources. An operator may have multiple kernels; the compiler selects the best match based on tensor signatures and the optional predicate.

Fields marked "prepare-only" may be zero/NULL in execute-only builds.
