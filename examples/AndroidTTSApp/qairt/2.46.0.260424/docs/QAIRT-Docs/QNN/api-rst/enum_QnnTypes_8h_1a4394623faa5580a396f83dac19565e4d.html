enum Qnn_Priority_t¶

An enum to specify a priority.

Values:

enumerator QNN_PRIORITY_LOWEST = 0¶

QNN_PRIORITY_LOW is always available for use.

enumerator QNN_PRIORITY_LOW = QNN_PRIORITY_LOWEST¶
enumerator QNN_PRIORITY_NORMAL_LOW = 50¶
enumerator QNN_PRIORITY_NORMAL = 100¶

QNN_PRIORITY_NORMAL usage may be restricted.

enumerator QNN_PRIORITY_DEFAULT = QNN_PRIORITY_NORMAL¶
enumerator QNN_PRIORITY_NORMAL_HIGH = 150¶

QNN_PRIORITY_NORMAL_HIGH usage may be restricted.

enumerator QNN_PRIORITY_HIGH = 200¶

QNN_PRIORITY_HIGH usage may be restricted.

enumerator QNN_PRIORITY_HIGH_PLUS = 300¶

QNN_PRIORITY_HIGH_PLUS usage may be restricted.

enumerator QNN_PRIORITY_CRITICAL = 400¶

QNN_PRIORITY_CRITICAL usage may be restricted.

enumerator QNN_PRIORITY_CRITICAL_PLUS = 500¶

QNN_PRIORITY_CRITICAL_PLUS usage may be restricted.

enumerator QNN_PRIORITY_HIGHEST = QNN_PRIORITY_CRITICAL_PLUS¶

QNN_PRIORITY_HIGHEST usage may be restricted.

enumerator QNN_PRIORITY_UNDEFINED = 0x7FFFFFFF¶
