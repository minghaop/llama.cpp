Enum Documentation¶

enum Qnn_QuantizationEncoding_t¶

An enum to specify quantization encoding type structure.

Values:

enumerator QNN_QUANTIZATION_ENCODING_SCALE_OFFSET = 0¶

Indicates per-tensor scale-offset encoding type. See Qnn_ScaleOffset_t. Support can be checked via QNN_PROPERTY_TENSOR_SUPPORT_QUANTIZATION_ENCODING_SCALE_OFFSET.

enumerator QNN_QUANTIZATION_ENCODING_AXIS_SCALE_OFFSET = 1¶

Indicates per-axis (e.g. per-channel) scale-offset encoding type. See Qnn_AxisScaleOffset_t. Support can be checked via QNN_PROPERTY_TENSOR_SUPPORT_QUANTIZATION_ENCODING_AXIS_SCALE_OFFSET.

enumerator QNN_QUANTIZATION_ENCODING_BW_SCALE_OFFSET = 2¶

Indicates bit-width scale-offset encoding type. See Qnn_BwScaleOffset_t. Support can be checked via QNN_PROPERTY_TENSOR_SUPPORT_QUANTIZATION_ENCODING_BW_SCALE_OFFSET.

enumerator QNN_QUANTIZATION_ENCODING_BW_AXIS_SCALE_OFFSET = 3¶

Indicates bit-width per-axis scale-offset encoding type. See Qnn_BwAxisScaleOffset_t. Support can be checked via QNN_PROPERTY_TENSOR_SUPPORT_QUANTIZATION_ENCODING_BW_AXIS_SCALE_OFFSET.

enumerator QNN_QUANTIZATION_ENCODING_BLOCK = 4¶

Indicates per-block scale-offset encoding type. See Qnn_BlockEncoding_t. Support can be checked via QNN_PROPERTY_TENSOR_SUPPORT_QUANTIZATION_ENCODING_BLOCK.

enumerator QNN_QUANTIZATION_ENCODING_BLOCKWISE_EXPANSION = 5¶

Indicates per-block scale-offset encoding type. See Qnn_BlockwiseExpansion_t. Support can be checked via QNN_PROPERTY_TENSOR_SUPPORT_QUANTIZATION_ENCODING_BLOCKWISE_EXPANSION.

enumerator QNN_QUANTIZATION_ENCODING_VECTOR = 6¶

Indicates VQ compression encoding type. See Qnn_VectorQuantCompression_t. Support can be checked via QNN_PROPERTY_TENSOR_SUPPORT_QUANTIZATION_ENCODING_VQ_COMPRESSION.

enumerator QNN_QUANTIZATION_ENCODING_FLOAT_BLOCK = 7¶

Indicates per-block float scale-offset encoding type. See Qnn_FloatBlockEncoding_t. Support can be checked via QNN_PROPERTY_TENSOR_SUPPORT_QUANTIZATION_ENCODING_FLOAT_BLOCK.

enumerator QNN_QUANTIZATION_ENCODING_BW_AXIS_SCALE_OFFSET_MAPPED = 8¶

Indicates bit-width per-axis scale-offset mapped encoding type. See Qnn_BwAxisScaleOffsetMapped_t. Support can be checked via QNN_PROPERTY_TENSOR_SUPPORT_QUANTIZATION_ENCODING_BW_AXIS_SCALE_OFFSET_MAPPED.

enumerator QNN_QUANTIZATION_ENCODING_BW_BLOCK_MAPPED = 9¶

Indicates per-block scale-offset, bw, mapped encoding type. See Qnn_BwBlockMapped_t. Support can be checked via QNN_PROPERTY_TENSOR_SUPPORT_QUANTIZATION_ENCODING_BW_BLOCK_SCALE_OFFSET_MAPPED.

enumerator QNN_QUANTIZATION_ENCODING_BW_BLOCKWISE_EXPANSION_MAPPED = 10¶

Indicates per-block scale-offset encoding type. See Qnn_BwBlockwiseExpansionMapped_t. Support can be checked via QNN_PROPERTY_TENSOR_SUPPORT_QUANTIZATION_ENCODING_BW_BLOCKWISE_EXPANSION_MAPPED.

enumerator QNN_QUANTIZATION_ENCODING_BW_FLOAT_BLOCK = 11¶

Indicates bit-width per-block float scale-offset encoding type. See Qnn_BwFloatBlockEncoding_t. Support can be checked via QNN_PROPERTY_TENSOR_SUPPORT_QUANTIZATION_ENCODING_BW_FLOAT_BLOCK.

enumerator QNN_QUANTIZATION_ENCODING_MICROSCALING = 12¶

Indicates Microscaling(MX) encoding type. See Qnn_MicroscalingEncoding_t. Support can be checked via QNN_PROPERTY_TENSOR_SUPPORT_QUANTIZATION_ENCODING_MICROSCALING.

enumerator QNN_QUANTIZATION_ENCODING_ARRAY_OF = 13¶

Indicates that an array of encodings is present. The actual encoding type is specified by the array structure.

enumerator QNN_QUANTIZATION_ENCODING_UNDEFINED = 0x7FFFFFFF¶
