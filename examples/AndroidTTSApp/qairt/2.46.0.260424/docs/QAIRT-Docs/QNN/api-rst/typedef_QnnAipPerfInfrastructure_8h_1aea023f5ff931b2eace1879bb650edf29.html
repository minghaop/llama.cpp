typedef uint32_t QnnAipPerfInfrastructure_VtcmSize_t¶

sets the vtcm size to use for graphs that are prepared offline. This API should be set up before users can finalize a graph offline. It allows the QNN DSP backend to configure the serialized context for the available vtcm on target

VTCM size provided in MB and does not have a default
