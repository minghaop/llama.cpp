GenieDialog_batchQuery¶

See Genie Dialog JSON configuration string for details on the fields and what they mean. An example model_config can be found at ${QNN_SDK_ROOT}/examples/Genie/configs/llama3-8b-htp-batch-query.json.

Tutorial on how to use GenieDialog_batchQuery in genie-app¶

Note

Only support frozen non-weight-shared multi_batch AR-N models and basic dialog.

Script for genie-app¶
profile create profile1

dialog config create config1 llama3-8b-htp-batch-query.json

dialog config bind profile config1 profile1

dialog create dialog1 config1

dialog setPerformance dialog1 GENIE_PERFORMANCE_BURST

dialog batchQuery dialog1 query1.txt query2.txt

profile save profile1 profile1.json

dialog config free config1

dialog free dialog1

profile free profile1
