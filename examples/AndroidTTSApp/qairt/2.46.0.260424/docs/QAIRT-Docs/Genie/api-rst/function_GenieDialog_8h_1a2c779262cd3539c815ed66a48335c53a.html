Function GenieDialog_getTokenizer¶

  • Defined in File GenieDialog.h

Function Documentation¶

Genie_Status_t GenieDialog_getTokenizer(const GenieDialog_Handle_t dialogHandle, GenieTokenizer_Handle_t *tokenizerHandle)¶

A function to get the tokenizer handle associated with a dialog.

Parameters

  • dialogHandle – [in] A dialog handle.

  • tokenizerHandle – [in] A tokenizer handle tied to dialogHandle. Must not be NULL.

Returns

Status code:

  • GENIE_STATUS_SUCCESS: API call was successful.

  • GENIE_STATUS_ERROR_INVALID_HANDLE: Dialog handle is invalid.

  • GENIE_STATUS_ERROR_INVALID_ARGUMENT: At least one argument is invalid.

  • GENIE_STATUS_ERROR_GET_HANDLE_FAILED: Get tokenizer failure.
