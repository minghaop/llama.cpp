Function GenieDlc_create¶

  • Defined in File GenieDlc.h

Function Documentation¶

Genie_Status_t GenieDlc_create(const GenieDlcConfig_Handle_t configHandle, GenieDlc_Handle_t *dlcHandle)¶

A function to create a DLC.

Parameters

  • configHandle – [in] A handle to a valid config. Must not be NULL.

  • dlcHandle – [out] A handle to the created DLC. Must not be NULL.

Returns

Status code:

  • GENIE_STATUS_SUCCESS: API call was successful.

  • GENIE_STATUS_ERROR_INVALID_HANDLE: Config handle is invalid.

  • GENIE_STATUS_ERROR_INVALID_ARGUMENT: At least one argument is invalid.

  • GENIE_STATUS_ERROR_MEM_ALLOC: Memory allocation failure.
